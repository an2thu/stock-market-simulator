# Stock Market Analysis and Portfolio Simulator

A Python application for analyzing real stock market data, calculating technical indicators, and simulating investment portfolios.

## Features
- Real-time stock data from Yahoo Finance API
- Technical indicators (SMA 20, SMA 50, volatility)
- Portfolio tracking with profit/loss calculations
- Backtesting framework for trading strategies
- Interactive charts and visualizations

## Tech Stack
- **Backend:** Python Flask, SQLite
- **Data Sources:** Yahoo Finance API (yfinance)
- **Analysis:** pandas, NumPy
- **Visualization:** matplotlib, Chart.js

## Key Achievements
- Analyzed 50+ stocks across 12 months of historical data
- Implemented backtesting framework for strategy evaluation
- Created portfolio analytics with risk metrics
- Built automated chart generation system
